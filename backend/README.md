# habit-flow (현재 고도화 진행 중)
> 트래픽 확장성을 고려한 B2C 일정/습관 관리 도메인 아키텍처 구축 프로젝트

- **목적:** 데이터 병목 제어 및 모던 백엔드(Spring Boot 3.x / JPA) 기술 내재화
- **현재 진행 상황 (24년 6월 기준):** - Spring Boot 3.x 및 Spring Data JPA 도메인 모델링 완료
    - QueryDSL을 활용한 다중 조건 동적 쿼리 구현 및 복합 조회 성능 최적화 완료
    - N+1 문제 해소 및 Redis 분산 락을 활용한 트래픽 동시성 제어 파이프라인 구축 진행 중
